How to read the results

The noise channel is shared; the new belief tools are MB-only

Same observation channel

Gaussian noise on object pose and, for the combined boil point, scalar readings.

Sigmas are declared to both arms. Repeated observation at the same step returns the same draw.

MF stays a plain code agent and may write its own smoothing.

What we measure

Solve rate: fraction of train + test levels solved, over all seeds.

Steps: whole-run total, averaged only over seeds solving both levels.

Resets: mean across all seeds.

No successful seed means N/A steps, never zero steps.

Noiseless references: seed 0 only. Noisy conditions: seeds 0 and 1.
Skills and evaluators retain true state; this tests the agent's observation and decision channel.

What changed for MB

Six flags, enabled together in the validation runs

01

Parameter intervals

Retain informative but wide fits and test plans across their intervals.

02

Noise-aware probes

Value a probe by whether its noisy observation can distinguish models.

03

Fit-side filtering

Find rest and motion relative to sigma; start rollouts from denoised rest windows.

04

Carried fit center

Use the last applied MAP as the next prior center; do not carry its width.

05

Laplace evidence

Report fit quality with a complexity penalty and comparable version deltas.

06

Execution belief

Expose smoothed state, spread and atom fractions for planning and monitoring.

The agent still writes the model and chooses actions.
The added machinery exposes uncertainty to those decisions.
All six flags default off. The domino v2 and boil p12_r07 MB configs enable them; MF does not receive the harness belief frame.

1 · Parameter intervals / 2 · Noise-aware probes

A wide, informative fit should not fall back to an implausible anchor

Retain the estimate

A moved, informative but wide posterior gets the WIDE verdict and can deploy its MAP.

Test the interval

Plan sweeps report the fraction of parameter settings that pass and where outcomes change.

Probe when it matters

A mixed sweep can trigger information seeking. Probe value accounts for noisy readings.

The interval illustration is from the earlier failure analysis, not a fitted-parameter trace from the new winning runs. A parameter that did not move or remains wider than its prior still falls back to the anchor. Noise-aware probe scoring uses mutual information over eight noisy reads per ensemble member, not raw prediction spread.
3 · Fit-side filtering / 4 · Carried center / 5 · Evidence

Improve what the fit sees and what survives the next fit

Fit-side filtering

Detect motion from window means relative to the declared sigma.

Start a rest-anchored rollout from an averaged frame.

spread ≈ σ / √n

This reduces initial-state noise while the object is at rest.

Carry the prior center

The last applied MAP becomes the next fit's prior center.

The width is not carried.

Fits already pool past levels' data; carrying its posterior width would count those data twice.

Compare by evidence

Report Laplace log evidence from the fit's residuals and local curvature.

Include a complexity penalty and comparable version deltas.

This informs the agent's choice; it is not an automatic model-replacement rule.

Sources: trajectory_prep.py; agent_sim_learning_approach.py; synthesis_backend.py; evidence.py.
11
Angles use circular means. Rest detection compares windows using their standard errors, with the configured settle tolerance as a floor. Evidence may be unavailable when the fit lacks suitable curvature. Version comparisons are reported only when the implementation considers the scored residual data comparable.
6 · Execution belief / tools available to the agent

Expose spread, test sensitivity, then act

Execution-time belief

Average each object's noisy features over a recent window consistent with rest.

Shorten the window when its two half-means disagree beyond the noise threshold.

Expose the mean, spread and atom fractions beside the raw observation.

Slow motion can pass this heuristic and cause lag. Expected-atom checks use fractions over belief draws.

sim.belief()

Read the current smoothed features, spreads and atom fractions.

sim.run(..., belief_draws=K)

Vary the starting state to test sensitivity to observation uncertainty.

sim.run(..., physics_sweep=True)

Sweep the learned parameter intervals.

evaluate_trajectory(...,
physics_sweep=True)

Score the recorded sequence across parameter settings.

Not built: a full particle filter or observation-belief draws in evaluate_trajectory.
Atom fractions live in the observation and sim.belief(), not sim.predicates().
Sources: observation_belief.py; run/continual.py; agent_sdk/belief_probe.py.
12
The execution belief is a rest-window smoother, not a particle filter tracking moving latent states. The scalar-reading channel is shared by both arms and folds into the same sigma-aware fit and belief calculations. Physics sweeps and start-state belief draws are separate tool modes.
Interpretation

Recovery is observed; the contribution of each feature is still open

What the runs show

Domino at 1 cm: both MB seeds now solve both levels; the earlier MB pair did not.

Boil, combined noise: MB solves all four levels across seeds, with zero resets; MF solves one.

All four new MB runs finish successfully.

What they do not isolate

Only two noisy seeds and one noiseless reference seed per arm.

Earlier MB runs use older code; individual feature ablations are still absent.

Boil has no matched feature-off run with reading noise, and its old noiseless references exposed hidden heat.

To support stronger claims: clean noiseless boil controls, matched feature ablations, and more seeds.
